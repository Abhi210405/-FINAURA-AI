# FINAURA AI — Prototype

## Project structure

- `index.html` — page structure and UI
- `styles.css` — complete visual styling, responsive layout and animated background
- `script.js` — user input, analysis logic, navigation, review actions and decision ledger

## Run locally

Open `index.html` in a browser.

No build step is required because this prototype uses HTML, CSS and vanilla JavaScript.

## Important

The prototype uses synthetic/simulated data for demonstration. It is not a production financial decision engine.
